## 2026-09-21~2026-09-26

하루 1회 간단 관찰:

- 두 실험 URL의 색인 상태
- canonical
- 실제 검색 Googlebot 재방문
- HTTP 또는 접근 오류

변화가 없으면 로컬 기록만 갱신한다. 의미 있는 변화, 새 차단·오류, 사용자 조치 필요 사항만 알린다. 광고 JavaScript를 실행하거나 반복 광고 노출을 만들지 않는다.

## 2026-09-27

미색인이 지속될 때만 심화 진단한다.

- Google 저장 HTML/렌더 확보 가능 여부
- 실제 서버 본문
- 내부 링크
- 중복 및 대표 URL

2026-09-20에는 미색인 URL의 저장 페이지 보기 버튼이 비활성이었다. 확보하지 못한 자료는 한계로 표시하고 임의로 색인을 재요청하지 않는다. 개선이 필요하면 근거와 정확한 변경 범위를 먼저 제안하고 승인받는다.
