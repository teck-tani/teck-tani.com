## 전제 / 선정 기준

- **시계 시스템(clock-tani.com) · 계산기 시스템(calc-tani.com)에서 개발한 도구는 전부 제외.** 본 100종은 teck-tani.com의 4개 카테고리(`image` / `text` / `life` / `devtools`)에 속하는 **비계산기·비시계 유틸**이다.
- **브라우저(클라이언트) 100% 처리 우선** — 파일 업로드 없음 = 개인정보 안전을 USP로.
- **현재 62종과 중복 0** — 같은 키워드라도 입력·목적·방향이 다르면 별도 도구로 채택(역방향 도구, 스캐너 등). 경계 근거는 하단 "중복 아님" 섹션 참조.
- **변환·표기 도구는 계산기가 아님** — 진법 변환·로마숫자·숫자한글표기 등은 산술이 아니라 표기 변환이므로 teck-tani 유틸(기존 unit/file-size/color-converter와 동류)로 분류. 순수 산술/금융 계산기는 calc-tani.com 소관이라 제외.

- **역방향 도구**: `qr-scanner`≠qr-generator · `barcode-scanner`≠barcode · `gif-splitter`≠gif-maker · `html-to-markdown`≠markdown-preview · `pdf-to-jpg`/`jpg-to-pdf`(기존)와 영상 변환은 입력 도메인 다름.
- **이미지 편집 세분화**: `image-crop`(자르기)·`image-rotate`(회전)는 기존 `image-resize`(크기 변경)와 작업이 다름. `photo-collage`(격자/템플릿)≠`image-merge`(선형 이어붙이기). `exif-remover`≠`photo-blur`(영역 가리기)/`image-converter`(포맷).
- **텍스트**: `sort-lines`/`find-replace`≠`text-cleaner`(공백·줄바꿈 제거)·`character-counter`·`text-diff`. `font-preview`(웹폰트 미리보기)≠`fancy-font`(유니코드 치환).
- **표기 변환은 계산기 아님**: `number-to-korean`·`roman-numeral`·`number-base-converter`는 산술이 아닌 표기 변환 → 기존 `unit-converter`·`file-size-converter`·`color-converter`와 동류. 금융/수학 계산기는 calc-tani 소관이라 본 리스트에서 제외.
- **JSON 군**: `json-yaml`·`json-to-typescript`·`json-diff`≠`json-formatter`(포맷/검증만)·`json-csv-converter`.
- **색상 군**: `color-blindness-simulator`·`gradient-generator`≠`color-converter`(코드 변환)·`contrast-checker`·`color-palette-generator`.
- **추첨 군**: `team-generator`·`name-picker`·`number-picker`·`seat-randomizer`는 용도 특화 → 범용 `random-generator`·`ladder-game`·`spin-wheel`과 UX·시나리오 분리.
- **보안 군**: `password-strength-checker`(검사)≠`password-generator`(생성). `mock-data-generator`(faker)≠`random-generator`(난수).

## 도구별 구현 패턴 (기존 규칙 재사용 — 신규 패턴 만들지 말 것)

각 도구는 `CLAUDE.md`의 "Adding a New Tool" 6단계를 따른다:
1. `src/config/tools.ts` `ALL_TOOLS`에 추가(href/labelKey/icon/category)
2. `src/app/[locale]/<slug>/page.tsx`(서버, 메타·JSON-LD) + `<Name>Client.tsx`(`"use client"`) — `base64-encoder/page.tsx` 템플릿
3. `force-static` + `revalidate=false` + `generateStaticParams`
4. `messages/ko.json`·`en.json` 번역(`Index.tools.*` + `<Name>.meta.*` + `<Name>.*`, 하드코딩 금지)
5. 하단 SEO 본문 6필수 섹션(도구설명·기능·사용법·활용예시·FAQ·개인정보) + FAQPage/HowTo/WebApplication JSON-LD
6. GitHub 공개 저장소 README에 도구 추가 + `src/app/sitemap.ts` `LAST_MODIFIED_MAP` 갱신

- Header/홈/사이트맵은 `tools.ts`에서 자동 파생.
- 공통 `.dt-*` 디자인 시스템 + `src/utils/{clipboard,format,fileDownload}.ts`, `src/components/{IconButton,Toast,DropZone}.tsx` 재사용.
- 제목은 Header만(본문 h1 금지, 페이지당 h1 1개), 다크모드는 `body[data-theme="dark"] .seo-*`.
