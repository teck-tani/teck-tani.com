# Teck-Tani.com

## 특징

- **다국어 지원** - 한국어 / 영어 (ko, en)
- **개인정보 보호** - 모든 데이터는 브라우저에서만 처리, 서버 전송 없음
- **완전 무료** - 모든 도구 무료 사용
- **모바일 지원** - 반응형 디자인

## 기술 스택

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- next-intl (i18n)
- Vercel (Hosting)
