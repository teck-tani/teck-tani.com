# Teck-Tani.com

## Features

- **Bilingual** - Korean / English (ko, en)
- **Privacy First** - All data processed in browser only, no server transmission
- **Free** - All tools are completely free
- **Mobile Friendly** - Responsive design for all devices

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- next-intl (i18n)
- Vercel (Hosting)
